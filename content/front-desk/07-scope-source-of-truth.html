2. Live — but read the caveat

Front Desk ships with 9 known rough edges. Each is live in production — quote the caveat verbatim before promising.

1. Greeting uses business name, not custom typed name

COMPLIANCE NOTE

Agent introduces itself with the business name even if owner has typed a custom agent name. Don't pitch "the agent will say its name on every call" — pitch "the agent opens with your business name."

2. Phone-number identity assumption

COMPLIANCE NOTE

If a regular's number is used by someone new, the agent may assume it's the regular. Set the expectation when a salon has shared family lines.

3. Dashboard appointment-time timezone

COMPLIANCE NOTE

Dashboard can show times in the viewer's own timezone, not the salon's. Customer-facing text is always correct — clarify this if the owner views the dashboard from a different timezone.

4. Wrong note in the Brain repeats

COMPLIANCE NOTE

If bad info gets saved to the Brain, the agent may relay it. Easily fixed by correcting the answer. Tell owners: "the agent is only as accurate as your Brain — review it."

5. Verify follow-up is switched on

COMPLIANCE NOTE

On by default but verify it's active for the account before promising on a specific deal. Always confirm in the dashboard before the demo.

6. It's AI — occasional mistakes

COMPLIANCE NOTE

Set this expectation up front. Don't promise a guaranteed number of bookings or revenue. The agent is very good, not perfect.

7. DND resume by incoming text unconfirmed

COMPLIANCE NOTE

Resume confirmed when customer CALLS back. Reactivating by incoming TEXT is still being firmed up. Promise only "we pick back up when you call us."

8. Call-forwarding doesn't forward inbound texts

COMPLIANCE NOTE

Option 1 (call forwarding from existing number) does NOT forward inbound SMS — agent won't reply to inbound texts in that setup. If inbound SMS reply is critical, recommend porting or putting the agent number on Google instead.

9. Don't say "we'll forward your line for you"

COMPLIANCE NOTE

OWNER sets forwarding themselves via wizard. We don't change settings at their phone carrier. Position it as "we walk you through it step-by-step," not "we do it for you."

4. Out of Scope (do NOT promise)

Take deposit / card payment on the call

DON'T PROMISE

Even if deposit / card-required rules are switched on, agent does NOT charge the card during the call. Do NOT pitch "no-show protection by charging a card on the call."

Work without a connected booking calendar

DON'T PROMISE

7. Key terms (glossary)

  • The Brain — the agent's knowledge base for the salon. Services, prices, policies, FAQs. Pre-filled from Google + website at setup.
  • Person-to-reach — the human number the agent transfers to during allowed transfer hours.
  • Lead recovery — the auto-chase for anyone who started but didn't book.
  • Quiet hours — roughly 9 PM – 7 AM local; agent holds outbound follow-ups until morning.
  • DND — Do Not Disturb. Caller-requested or STOP-keyword opt-out from follow-ups.
  • Disposition / outcome — the plain-English category every call gets tagged with (hot lead, question, spam, etc.) — drives the follow-up intensity.
  • Option 1 forwarding — using the call-forwarding wizard from the salon's existing number. Note: does NOT forward inbound SMS.
  • Card-required rule — config flag that requires a card on file before booking. Only works on Zoca Scheduling. Agent does NOT collect the card on call.
  • Person handoff vs. warm handoff — Front Desk does straight handoffs (transfer the call); warm handoff (briefing the person first) is out of scope.
